## 4. 工程改动

- `tests/src/clients/api.client.ts`：补齐热销、支付列表、管理端商品/清缓存等方法；支持匿名/指定 token 的 `raw()`；登录保存 refreshToken。
- `tests/src/fixtures.ts`：新增 `freshUser`（每用例独立注册用户）、`products`（自建商品并自动清理）、`runId` 隔离；修正原有 client 导入路径。
- `tests/src/specs/*.api.spec.ts`：按 M1~M6 重写为带 `[ID][层级][优先级]` 与 `@p0/@l1/@mN` 标签的用例，共 44 条 P0。
- `tests/package.json`：新增 `test:p0` / `test:p1` / `test:p2` / `typecheck`；锁定 `allure-playwright@3.0.5` 以兼容 Playwright 1.47.2。
- 数据隔离：每个用例使用 `runId + 序号` 独立用户；商品用例结束自动删除；支付配置用例 finally 恢复原值。
